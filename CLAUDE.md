# Capra Lab: notes for working in this repo

JC's game hub at capra-lab.netlify.app; Netlify deploys `main` automatically. README.md has the layout, the profile system and how to make a game native. The rules that are easy to miss:

- **Status bar buffer on every screen.** Nothing may sit under the iPhone status bar: the page runs under it from the home screen and iOS blurs it. `viewport-fit=cover`, then every screen, top bar, HUD and fixed layer starts at `env(safe-area-inset-top)` plus a margin (bottom and landscape sides too). Check with `Emulation.setSafeAreaInsetsOverride` (see README).
- **The Capra Lab button on every game's main menu** (JC: the lab logo, left of the player's name, in the same place in every game). It's `<capra-lab-chip>` from `public/lab/chip.js` (`noname` when the game shows the name itself right after it, as Mind Heist does). It goes first in the main menu's top row so the logo lands `max(16px, safe-left)` in and `safe-top + 10px` down in every game; keep that corner clear. Glacial Maw loads it from the lab only under `/glacial-maw/`.
- **Capra's Lab** (JC's private side: `lab/crew.js`, `public/lab/capras-lab.js`). JJ-Capra is the owner with master controls; his crew (DA_ROMAN_EMPIRE first; the owner adds or removes others on the hub, and only names that already have a profile) gets the same early access. Members see a CAPRA'S LAB panel on the hub: games in testing, every Mind Heist deck with a Hidden/Public switch (owner only), the crew list (owner only). Every request proves the profile with its key; never put anyone's key in code or chat.
- **"JJ Brew" means hidden from the public.** When JC calls a deck or a game a JJ Brew, it starts hidden: a Mind Heist deck gets `"brew": true` in `deck_plan.json` (no date); a game gets `<script src="/lab/brew.js"></script>` first in its page's `<head>` and its hub tile goes in `#clGames` (Capra's Lab's "In testing") instead of the public grid. It goes public only when JC says so (take both out, or flip the deck's switch).
- **One profile for every game.** Players are `localStorage['capra-lab.profile']` = `{ name, handle, code }` (names up to 17 characters, `NAME_MAX`, and every game shows all 17); servers check keys with `lab/profiles.js` (`verify`). Games keep their own stats keyed by handle. New players go to `/#profile` for the key-card walkthrough.
- **One place per route.** A path is mapped either in `netlify.toml` or by a function's `config.path`, never both.
- **Netlify treats `/x` and `/x/` as the same path.** Never write a redirect from `/x` to `/x/`: it loops and the page never loads (the local dev server doesn't show this). Link games with the trailing slash.
- Native games: Primal Survival, Par-Tee Time, Swerve Planet, Don't Look!, Mind Heist (`games/mind-heist/CLAUDE.md` has its rules; it builds with its own `build.mjs`, run by `scripts/build.mjs`), Goat Getaway (`games/goat-getaway/CLAUDE.md`; its diamonds land in Mind Heist's store). Glacial Maw is still its own site, proxied in `netlify.toml`, so its pages must work under a path prefix.
- `npm test` runs every suite; `npm run build && node scripts/dev-server.mjs` serves the lab locally.
- Commits: `git -c user.name="JC" -c user.email="caitlin.miah@gmail.com" commit`.
