## Content changes
- time-machine / Since 1990 / 100: the Dolly the sheep question duplicated A2 the-90s / Big Moments / 100, whose question is about Dolly's name. Replaced it by moving the Human Genome Project question (confirmed on genome.gov) up from $300.
- time-machine / Since 1990 / 200: the Channel Tunnel question was nearly word-for-word the same as A2 the-90s / Big Moments / 200. Replaced it with a new question: CERN announced the Higgs boson in 2012 (PBS NOVA: July 4, 2012; Higgs and Englert shared the 2013 Nobel).
- time-machine / Since 1990 / 300: this slot was emptied when the HGP question moved to $100. Added a new question: the Oresund Bridge (2000) links Denmark with Sweden (Wikipedia: opened 1 July 2000; it joins the tunnel on Peberholm).

- eureka / Happy Accidents / 400: the fact said "a gas cylinder turned into a waxy white solid", but the gas inside the cylinder solidified. Rewrote it.
- eureka / Old School Tech / 400: the question called the Archimedes screw "a machine from ancient Greece", but its origin is disputed (it may have earlier Assyrian roots). Reworded it to "named for the ancient Greek scientist".
- eureka / Modern Makers / 300: the fact line "QR stands for Quick Response" was the answer to A8 monday-mixer-3 / Spell It Out / 300. Replaced it with Masahiro Hara getting the idea during a lunchtime game of Go (Wikipedia, Masahiro Hara).
- eureka / Modern Makers / 400: "Sony began selling the first commercial lithium-ion batteries" ignores Asahi Kasei. Rewrote it as "first went on sale in 1991" (Nobel press release) and added that Goodenough was 97 when he won (Wikipedia).
- ancient-worlds / Far Horizons / 100: A4 around-the-world / Landmarks / 100 reads "The Inca citadel of Machu Picchu", which gives away this answer. That deck has no date, so it could be played first. Replaced the question: Mexico City stands on the site of the Aztec capital (Britannica, Tenochtitlan).
- monuments-memorials / Veterans Day / 400: this deck also has France's Tomb of the Unknown Soldier, so I added "Arlington's". The fact now uses Arlington's own wording: the 21-gun salute is "the highest military honor".
- evergreen-state / Lay of the Land: renamed the category to "Around the State", because the Expo '74 question is not geography. All four questions were confirmed.
- evergreen-state / Made in WA / 200: "first celebrated in Spokane" is a disputed first, because a 1908 service in Fairmont, W.Va. is also called the first Father's Day. Reworded it to "grew out of a celebration held in Spokane on June 19, 1910". The fact was confirmed (Wikipedia, HistoryLink 9458).
- evergreen-state / Made in WA / 400: the fact "started out selling only books" was the answer to A2 log-on / Web Firsts / 100. Replaced it with Amazon's own account that the first desks were doors with legs attached (aboutamazon.com).
- famous-firsts / Taking Flight / 100: "made the first powered airplane flight" invites the Whitehead claim. Reworded it to "their first powered airplane flights". The answer is unchanged.
- famous-firsts / Taking Flight / 400: reworded the fact to match the source: US schools would not admit her, so she studied French in Chicago and got her license in 1921.
- famous-firsts / Pioneers / 400: "coined the word 'cell'" is wrong, because the word already existed, and the "small bare rooms" explanation is a disputed story. The question now says "first used the word 'cell' in biology". The fact now says he described cork as full of tiny pores, "much like a honeycomb" (British Society for Haematology page).
- famous-firsts / Game Changers / 100: the No. 42 fact duplicated A7 sports-legends / Diamond Greats / 100. Replaced it with Robinson winning the first MLB Rookie of the Year award, later renamed for him (Wikipedia). Also added "modern" to "color barrier", because Moses Fleetwood Walker played in 1884.
- by-the-numbers / Math Magic / 300: the googol question duplicated A2 log-on / Garage Startups / 200, whose question text says "1 followed by 100 zeros". Replaced it with "XL in Roman numerals" (40). The distractors 60, 90 and 110 are the LX, XC and CX swaps.
- by-the-numbers / Math Magic / 100: "It began in 1988" overstated the record. Wikipedia calls 1988 the earliest known large-scale celebration. Reworded it to "The first big Pi Day party was held in 1988".
- clockwork / Tick Tock / 400: reworded the fact to "That definition set one second at...", so it stays true if the SI second is redefined.
